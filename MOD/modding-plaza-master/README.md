Welcome to the Modding Plaza
=======

## BMFont
BMFont is a Software used to create Paradox compatible Bitmap Fonts

## HOI4 Tree Snap v0.2
Script that allows you to generate a full pic of your focus tree in one click.

## Image Splitter
Allows you to take a bunch of pictures, or "Frames" and group them into one dds file, useful if you want to make animated stuff in HOI IV

## MapGen v2.2
Latest installment of the MapGen Software, previously known as ProvGen (v1.0 of ProvGen is also Provided on the Repo) It's a map that helps you create a HOI IV map from scratch.

## PDX Validator
A Script you run through your mod to find bugs and issues that wouldn't be detected by the errorlog otherwise, comes with a config.txt file to fine tune the settings of the script, after running the script it'll create a log.txt file, containing all the errors/bugs/issues detected

## ProvGen v1.0
Older version of MapGen

## QuickGFXInsert
Simple software/script, you set your HOI IV Path, your mod's path and it'll generate the goal.gfx and goal_shine.gfx in one click, cool isn't it?
